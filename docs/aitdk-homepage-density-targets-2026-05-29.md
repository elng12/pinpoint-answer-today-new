## 1. Core Rule

AITDK is the final answer.

Local scripts are only helpers. If the local script and AITDK disagree, use AITDK.

Judgment priority:

1. First check whether the target keyword order matches the table in this document.
2. Then check whether each group density is in the target range.
3. Then check whether random or unwanted phrases are taking top positions.

Density is not the first pass/fail question. The first pass/fail question is: did the requested keyword order show up?

Before changing homepage copy:

1. Open the local preview.
2. Check the AITDK Density panel.
3. Compare the result against this document.
4. Change the smallest visible copy block.
5. Check AITDK again.

Do not rewrite the whole homepage just because one phrase is out of order.

# Components Guide

组件按业务分两层：

- `components/site/`：站点壳子和通用页面区块
- `components/puzzles/`：和 Pinpoint 拼图业务直接相关的组件

`components/site/` 下当前分组：

- `analytics/`：站点统计脚本
- `contact/`：联系与反馈表单
- `home/`：首页专用区块
- `layout/`：导航、页脚、全站布局件
- `seo/`：结构化数据等 SEO 组件
- `ui/`：跨页面可复用的小型界面组件

`components/puzzles/` 下当前分组：

- `archive/`：归档页相关
- `detail/`：详情页相关
- `preview/`：预告页相关
- `shared/`：多个拼图页面共用的业务组件
